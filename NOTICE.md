## 3. Vendor-generated solver output

The folders `02_CFD_Fluent`, `03_Thermal_Structural_Mechanical` and `04_LS_DYNA_Extension` contain outputs of ANSYS Fluent, ANSYS Mechanical (MAPDL), ANSYS Workbench and LS-DYNA runs. These include logs, solver transcripts, exported data, figures and input decks.

About 85 files, mostly solver logs, contain vendor banners and copyright lines that were generated by the software and are retained unchanged. They include Synopsys and ANSYS copyright lines and LS-DYNA banners credited to Livermore Software Technology. Some logs also report the student licence state. These notices are kept as generated.

No vendor software, installer, licence file or vendor documentation is included. The analyses were run under ANSYS student licensing, and LS-DYNA was used through that licensing. The published student terms describe free student downloads as for educational use only: self-learning, student instruction, student projects and student demonstrations. Whether those terms permit publishing solver outputs was not confirmed in this audit. Until the owner has checked the applicable terms, this repository does not claim that solver outputs are freely redistributable.
